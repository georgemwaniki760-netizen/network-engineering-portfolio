# Small Business Network

## Project Status

🔄 Planned

## Overview

A simulated enterprise network designed for a small business environment.

## Objectives

- Design a logical network topology
- Implement VLAN segmentation
- Configure inter-VLAN routing
- Configure DHCP
- Implement ACLs
- Configure NAT/PAT
- Configure secure device management using SSH
- Test network connectivity
- Troubleshoot network failures
- Document the complete network
